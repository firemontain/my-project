## 一、模块定位

游戏流程模块是整个游戏的**主状态机**，负责驱动章节推进与游戏阶段切换。该模块不直接处理具体玩法逻辑，而是作为顶层调度器协调各子系统的运行节奏。

### 核心职责

1. **阶段状态管理**：维护并切换 CASINO / BUILD_SELECT / POKER / SETTLEMENT 四个核心阶段
2. **章节生命周期**：管理章节的初始化、推进、结算与重置
3. **目标达成判定**：判断关卡目标是否完成（收益目标、规模要求、特殊条件）
4. **全局节奏控制**：确保各子系统按统一生命周期运行

extends RefCounted

## 四、阶段切换流程规范

### 4.1 完整流程图

```
游戏启动
    ↓
章节选择界面
    ↓
[章节开始] GameManager.start_new_run(chapter_id)
    ├── 初始化 RunState
    ├── 加载 ChapterData
    ├── 发射 chapter_started 信号
    └── 进入 CASINO 阶段
           ↓
┌─────────────────────────────────────────────────────────────┐
│ CASINO 阶段                                                 │
│   - 玩家管理设施、接待NPC、触发经营事件                      │
│   - 监听 EconomyManager 资金变化                             │
│   - 退出条件：玩家点击"开始牌局"                             │
└─────────────────────────────────────────────────────────────┘
    ↓ 玩家主动触发 request_start_poker_session()
┌─────────────────────────────────────────────────────────────┐
│ BUILD_SELECT 阶段                                           │
│   - AbilityDraftSystem 执行抽卡                              │
│   - 玩家从候选牌中选择构建 Build                             │
│   - 退出条件：玩家确认选卡                                   │
└─────────────────────────────────────────────────────────────┘
    ↓ confirm_build_selection(selected_cards)
┌─────────────────────────────────────────────────────────────┐
│ POKER 阶段                                                  │
│   - PokerSessionMgr 驱动牌局                                 │
│   - 玩家使用能力卡、下注、与NPC对弈                          │
│   - 退出条件：牌局结束（PokerSessionMgr 发射信号）           │
└─────────────────────────────────────────────────────────────┘
    ↓ PokerSessionMgr.poker_session_ended 信号
┌─────────────────────────────────────────────────────────────┐
│ SETTLEMENT 阶段                                             │
│   - 执行奖惩计算                                             │
│   - ChapterObjectiveChecker 判定目标达成情况                 │
│   - 根据结果触发后续流程                                     │
└─────────────────────────────────────────────────────────────┘
    ↓
判断 ObjectiveResult
    ├── PASSED/PARTIAL → 下一关卡（回到 CASINO）或触发章节结算
    └── FAILED → BankruptcyHandler 执行惩罚
           ├── 轻度破产 → 惩罚后回到 CASINO
           └── 重度破产 → 章节重置
```

### 4.2 阶段切换触发条件表

| 源阶段 | 目标阶段 | 触发条件 | 触发者 |
|--------|----------|----------|--------|
| CASINO | BUILD_SELECT | 玩家点击"开始牌局"按钮 | 玩家主动 |
| BUILD_SELECT | POKER | 玩家确认选卡 | 玩家主动 |
| POKER | SETTLEMENT | poker_session_ended 信号 | 系统自动 |
| SETTLEMENT | CASINO | 关卡完成，进入下一关 | 系统自动 |
| SETTLEMENT | 章节结算 | 所有关卡完成 | 系统自动 |
| SETTLEMENT | CASINO | 轻度破产惩罚后 | 系统自动 |
| 章节结算 | 下一章节 | 章节奖励发放后 | 系统自动 |

## 五、EventBus 信号订阅

### 5.1 发射的信号

| 信号名称 | 参数 | 触发时机 |
|----------|------|----------|
| game_phase_changed | old_phase: int, new_phase: int | 阶段切换时 |
| run_started | 无 | 新运行开始时 |
| run_ended | result: StringName | 运行结束时（通关/失败） |
| chapter_completed | chapter_id: String | 章节完成时 |

### 5.2 监听的信号

| 信号名称 | 来源模块 | 响应行为 |
|----------|----------|----------|
| poker_session_ended | PokerSessionMgr | 触发 POKER → SETTLEMENT 切换 |
| bankruptcy_triggered | EconomyManager | 记录破产事件，影响结算逻辑 |
| chapter_objective_updated | 内部 | 更新目标进度展示 |
