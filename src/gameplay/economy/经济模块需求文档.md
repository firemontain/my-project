## 一、模块定位

经济模块是游戏的**资金总账系统**，负责全局资金流转、破产判定与资产变更记录。所有游戏内的收支操作必须通过本模块进行，确保资金口径统一、流向可追踪。

### 核心职责

1. **资金管理**：维护玩家当前资金、本章累计收益、历史交易记录
2. **破产判定**：监控资金状态，触发轻度/重度破产惩罚
3. **交易记录**：记录每笔收支的类型、金额、来源，支持审计追溯
4. **跨模块通知**：资金变化通过信号广播，驱动 UI 和其他系统响应

```gdscript
# gameplay/economy/EconomyTransaction.gd
class_name EconomyTransaction
extends RefCounted

enum TransactionType {
    ## 收入类型
    POKER_WIN,              # 牌局胜利收入
    PASSIVE_INCOME,         # 设施被动收入
    CHAPTER_BONUS,          # 章节奖励
    EVENT_REWARD,           # 事件奖励
    
    ## 支出类型
    FACILITY_UPGRADE,       # 设施升级
    ABILITY_PURCHASE,       # 能力卡购买
    EVENT_PENALTY,          # 事件惩罚
    BANKRUPTCY_PENALTY      # 破产惩罚
}

## 交易类型
var type: TransactionType

## 交易金额（正数为收入，负数为支出）
var amount: int

## 交易来源描述（如 NPC ID、设施 ID）
var source: String

## 交易发生时间戳
var timestamp: float

## 交易发生时的章节索引
var chapter_index: int

## 交易发生时的关卡索引
var stage_index: int

## 附加数据（可选，用于详细审计）
var metadata: Dictionary = {}

## 创建交易记录
static func create(
    type: TransactionType,
    amount: int,
    source: String,
    chapter: int = 0,
    stage: int = 0
) -> EconomyTransaction:
    var t := EconomyTransaction.new()
    t.type = type
    t.amount = amount
    t.source = source
    t.timestamp = Time.get_unix_time_from_system()
    t.chapter_index = chapter
    t.stage_index = stage
    return t
```

### 3.1 EconomyManager 单例

```gdscript
# autoloads/EconomyManager.gd
extends Node

## ── 信号定义 ──
signal funds_changed(new_amount: int, delta: int)
signal transaction_recorded(transaction: EconomyTransaction)
signal bankruptcy_triggered(severity: int)
signal chapter_revenue_updated(current: int, target: int)

## ── 状态持有 ──
var _state: EconomyState = EconomyState.new()
var _bankruptcy_handler: BankruptcyHandler = BankruptcyHandler.new()
var _transaction_history: Array[EconomyTransaction] = []

## ── 只读属性 ──
var current_funds: int:
    get: return _state.current_funds

var chapter_revenue: int:
    get: return _state.chapter_revenue

## ── 资金操作方法 ──

## 增加资金（收入）
## @param amount: 金额（必须为正数）
## @param type: 交易类型
## @param source: 来源描述
func add_funds(amount: int, type: EconomyTransaction.TransactionType, source: String) -> void:
    assert(amount > 0, "add_funds amount must be positive")
    _state.current_funds += amount
    _state.chapter_revenue += amount
    
    # 根据类型更新分类统计
    match type:
        EconomyTransaction.TransactionType.POKER_WIN:
            _state.poker_earnings += amount
        EconomyTransaction.TransactionType.PASSIVE_INCOME:
            _state.passive_earnings += amount
    
    # 记录交易
    var tx := EconomyTransaction.create(type, amount, source)
    _record_transaction(tx)
    
    # 发射信号
    funds_changed.emit(_state.current_funds, amount)

## 扣除资金（支出）
## @param amount: 金额（必须为正数）
## @param type: 交易类型
## @param source: 来源描述
## @return: 是否成功扣除
func deduct_funds(amount: int, type: EconomyTransaction.TransactionType, source: String) -> bool:
    assert(amount > 0, "deduct_funds amount must be positive")
    
    if not _state.can_afford(amount):
        return false
    
    _state.current_funds -= amount
    _state.chapter_expenses += amount
    
    # 根据类型更新分类统计
    match type:
        EconomyTransaction.TransactionType.FACILITY_UPGRADE:
            _state.facility_spending += amount
            _state.total_facility_investment += amount
        EconomyTransaction.TransactionType.ABILITY_PURCHASE:
            _state.ability_card_spending += amount
    
    # 记录交易
    var tx := EconomyTransaction.create(type, -amount, source)
    _record_transaction(tx)
    
    # 发射信号
    funds_changed.emit(_state.current_funds, -amount)
    
    # 检查破产
    _check_and_trigger_bankruptcy(false)
    
    return true

## 检查是否可以支付
func can_afford(amount: int) -> bool:
    return _state.can_afford(amount)

## ── 破产处理 ──

## 检查并触发破产（内部方法）
func _check_and_trigger_bankruptcy(is_settlement: bool) -> void:
    var chapter_data := GameManager.get_current_chapter_data()
    var required_revenue := chapter_data.required_revenue if chapter_data else 0
    
    var severity := _bankruptcy_handler.check_bankruptcy(
        _state.current_funds,
        _state.chapter_revenue,
        required_revenue,
        is_settlement
    )
    
    if severity != BankruptcyHandler.BankruptcySeverity.NONE:
        var penalty := _bankruptcy_handler.calculate_penalty(severity, _state)
        _execute_bankruptcy_penalty(penalty)
        bankruptcy_triggered.emit(severity)

    if penalty.funds_penalty > 0:
        _state.current_funds = maxi(0, _state.current_funds - penalty.funds_penalty)
    
    # 通过 EventBus 通知设施降级（不直接调用 CasinoManager）
    # CasinoManager 订阅 bankruptcy_triggered 信号处理降级

## ── 章节管理 ──

## 章节开始时初始化
func start_chapter(initial_funds: int) -> void:
    _state.current_funds = initial_funds
    _state.reset_chapter_stats()
    _transaction_history.clear()

## 章节结算时调用
func settle_chapter() -> void:
    _check_and_trigger_bankruptcy(true)

## ── 查询方法 ──

    return _state

func get_transaction_history() -> Array[EconomyTransaction]:
    return _transaction_history

func get_net_revenue() -> int:

func _record_transaction(tx: EconomyTransaction) -> void:
    _transaction_history.append(tx)
    transaction_recorded.emit(tx)
```

## 四、破产机制详细规范

### 4.1 轻度破产

**触发条件**：游戏过程中资金归零（current_funds <= 0）

**惩罚内容**：
1. 随机降级 1 个设施（对应能力卡暂时退出池）
2. 扣除本章部分积累资金（30%）

**保留内容**：
- 主线进度
- NPC 档案
- 能力池结构

**处理流程**：
```
资金归零
    ↓
BankruptcyHandler.check_bankruptcy() 返回 LIGHT
    ↓
EconomyManager 发射 bankruptcy_triggered(LIGHT) 信号
    ↓
CasinoManager 订阅信号，执行设施降级
    ↓
UIManager 展示破产惩罚弹窗
    ↓
游戏继续，玩家回到 CASINO 阶段
```

### 4.2 重度破产

**触发条件**：章节结算时未达收益目标（chapter_revenue < required_revenue）

**惩罚内容**：
1. 降级 2-3 个设施
2. 当前章节需重新完成

**保留内容**：
- 主线进度
- 已通关章节
- 已解锁能力池上限
- 本章节内已解锁的剧情碎片

**处理流程**：
```
结算阶段：章节收益 < 目标收益
    ↓
BankruptcyHandler.check_bankruptcy() 返回 HEAVY
    ↓
EconomyManager 发射 bankruptcy_triggered(HEAVY) 信号
    ↓
CasinoManager 执行多设施降级
NarrativeManager 标记保留的剧情碎片
GameManager 重置章节进度
    ↓
UIManager 展示重度破产剧情/弹窗
    ↓
章节重新开始
```

## 五、EventBus 信号交互

### 5.1 发射的信号

| 信号名称 | 参数 | 触发时机 |
|----------|------|----------|
| funds_changed | new_amount: int, delta: int | 任何资金变化时 |
| bankruptcy_triggered | severity: int | 触发破产时 |
| chapter_objective_updated | objective_id: String, progress: float | 收益进度更新时 |

### 5.2 监听的信号

| 信号名称 | 来源模块 | 响应行为 |
|----------|----------|----------|
| poker_session_ended | PokerSessionMgr | 结算牌局收益 |
| facility_upgraded | CasinoManager | 记录设施支出 |
| chapter_started | GameManager | 初始化章节经济状态 |
| game_phase_changed | GameManager | 在 SETTLEMENT 阶段触发结算检查 |
