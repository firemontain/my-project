## 一、游戏定位与核心体验

### 游戏类型
模拟经营 + 轻肉鸽心理战扑克。核心参考：《咩咩启示录》结构 + 《哈迪斯》叙事手法。

### 核心体验
玩家扮演赌场老板，亲自下场用"场外能力"操控 NPC 的心理弱点赢取暴利。
**核心爽点**：降维打击的掌控感——玩家不靠牌技，靠"把对手的大脑当棋盘"。

### 两层循环的主从关系
**牌局层是主轴，经营层是基础设施。** 经营层的核心价值在于：为牌局提供能力池、引流目标 NPC、通过设施联动强化牌局表现。亲自下场打牌始终是最高收益、最高爽点的体验路径。

经营路线作为**可行的替代策略**存在（而非等价替代），通过堆叠设施被动收益和设施联动能力，降低对牌局爆发的依赖度。两条路线的比重在游戏前期约为 6（牌局）：4（经营），后期经营压力上升，比重向经营倾斜——但核心叙事和爽点始终围绕牌桌。

### 整体框架

```
赌场经营层（持久化，章节间永不完全重置）
    ↓ 升级设施 → 扩充牌局能力池 + 决定 NPC 出现条件
牌局层（轻肉鸽，每场独立 Build，结束后归零）
    ↓ 胜负结果 → 推进主线剧情 + 解锁 NPC 档案
章节主线（流水叙事，有明确结局）
    ↓ 特殊/精英 NPC 是叙事锚点，有专属触发条件
破产惩罚：损失部分赌场资产，但保留主线进度 + 能力池
```

## 二、宏观经营层（Casino Management）

### 核心定位
赌场是玩家"延伸的身体"——每个设施都是玩家意志的物理化体现。经营层服务三个目的：
1. **底线保障**：普通赌客流水覆盖章节目标金额
2. **精准引流**：设施组合决定哪类 NPC 进门、是否触发精英/特殊 NPC
3. **能力外包**：设施升级直接扩充牌局能力池，经营投入 = 战斗力投入

### 两条路线的资源分配

玩家的每一分收益都面临同一个选择：扩张设施还是强化牌局能力。两条路线都可以完成目标，但风险结构不同：

| | 重经营路线 | 重牌局路线 |
|--|-----------|-----------|
| **资源流向** | 扩张设施、增加桌数 | 购买能力卡、强化千数 |
| **收益来源** | 普通赌客流水为主，牌局锦上添花 | 精英 NPC 爆发收益为主 |
| **后期优势** | 稀有 NPC 主动进门，被动能力堆叠厚 | Boss/精英牌局胜率高，单场收益极高 |
| **风险点** | 设施投入回报周期长，前期收益压力大 | 依赖精英 NPC 进门，经营规模不足时 NPC 不出现 |

### 多维度关卡目标

| 指标 | 类型 | 说明 |
|------|------|------|
| **收益目标** | 必须达成 | 不达标即触发破产惩罚 |
| **赌场规模指标** | 软约束 | 赌场评级影响奖励档次和精英 NPC 出现条件 |
| **特殊关卡条件** | 可选/强制 | 如「本关必须接待特定类型 NPC」，引导玩家尝试不同策略 |

### 设施-牌局联动示例

| 设施 | 经营效果 | 牌局联动效果 |
|------|---------|-------------|
| 酒吧区 | 吸引情绪型赌客 | 进场 NPC 基础压力+15，更易触发陷阱 |
| 千数后台 | 解锁出千系能力卡池 | 牌局内可使用换牌/记牌类场外能力 |
| 豪华包厢 | 吸引高净值精英 NPC | 每局开牌前有一次偷看底牌机会 |
| 情报网络 | 自动收集 NPC 弱点情报 | 进入牌局前可预览目标心理阈值 |
| 保安团队 | 防止 NPC 中途离场 | 陷阱触发后 NPC 无法弃牌（强制跟注） |

> **注**：「千数后台」等设施解锁的是**能力卡进入抽池的资格**，未升级该设施时，对应流派的能力卡不会出现在抽取选项中。设施降级后该类能力卡暂时退出池子，重新升级后恢复。

### 高频决策点（每关 3-5 次）
1. **资金分流**：本关盈利投入设施扩张 vs 购买牌局能力卡
2. **引流调配**：当前目标 NPC 需要什么设施组合才会进门
3. **经营事件响应**：每关 1-2 个随机事件（设备故障、税务检查、神秘顾客），处理方式影响奖励类型
4. **设施升级时机**：优先升能力联动设施（直接强化牌局）还是引流设施（长线收益）

## 三、微观博弈层（Show Hand 心理战）

### 梭哈结构（五张种马）
每人 1 张底牌（暗）+ 逐轮亮出 4 张明牌，共 4 轮下注。

每轮下注**前**有一个**行动窗口**，玩家消耗行动点（AP）使用场外能力。行动窗口在下注提交前触发，确保每个能力的使用都对当轮下注产生直接影响：

```
发牌 → [行动窗口] → 第1轮下注
亮第3张 → [行动窗口] → 第2轮下注
亮第4张 → [行动窗口] → 第3轮下注
亮第5张 → [行动窗口] → 第4轮下注（最终轮）→ 摊牌
```

### 行动点（AP）规则
- 每局开始时玩家获得 **4 AP**
- 每个行动窗口可自由分配 AP，不强制当轮消费
- 每张能力卡标注 AP 消耗（1-2 AP），出千类能力消耗较高（2 AP）
- AP 不跨局积累，牌局结束后清零

### 场外能力类型

| 类型 | 例子 | AP 消耗 | 效果层 |
|------|------|---------|--------|
| 情报类 | 偷看底牌、读取档案 | 2 AP | 消除信息不对称 |
| 生理攻击类 | 秒跟注、假装犹豫、敲击桌面 | 1 AP | 注入 NPC 生理系统（兴奋/压力波动） |
| 出千类 | 换牌、标记牌 | 2 AP | 直接修改牌面信息 |
| 环境联动类 | 服务生扰动、调暗灯光 | 1 AP | 需赌场设施解锁，全桌生效 |

### NPC 三位一体心理引擎

| 系统 | 核心变量 | 职责 |
|------|---------|------|
| **生理系统** | 兴奋度、压力值 | 随牌局走势和玩家小动作实时波动 |
| **理性系统** | EV（期望值） | 正常状态下按数学胜率做跟注/弃牌决策 |
| **陷阱系统** | 阈值触发器 | 生理指标达阈值时强制覆写理性系统，触发非理性重注 |

### 具体 Combo 举例

**Combo 1：「将计就计」—— 用对手的强牌反杀**

适用场景：目标 NPC 持有强底牌，明牌也强，高自信状态。AP 分配：共消耗 4 AP（偷看2 + 秒跟注1 + 敲击桌面1），出千换牌需要已持有该能力卡。

1. 发牌后行动窗口（2 AP）：使用「偷看底牌」确认对手暗 A
2. 第1轮：故意小注示弱，引 NPC 大注
3. 第2轮行动窗口（1 AP）：使用「秒跟注」→ NPC 兴奋度+25（误判玩家虚张）
4. 第3轮行动窗口（1 AP）：使用「敲击桌面」→ NPC 压力+20、兴奋度+15；同时使用「出千换牌」（若携带该牌，此卡自带1次免费使用）→ 将弱牌换成赢牌
5. 第4轮：NPC 生理阈值突破 → 陷阱「过度自信」触发，强制全押
6. 摊牌：玩家赢下全部筹码

**Combo 2：「苦肉计」—— 主动喂饭触发损失厌恶**

适用场景：目标 NPC 陷阱系统为「损失厌恶型」（输掉30%资金时强制跟注）。

> **前置说明**：梭哈中玩家可通过「主动弃牌」将当前轮底池让给对手，这是正常的牌桌操作，无需额外能力。故意输牌即通过策略性弃牌实现。

1. 第1-2轮：在自己牌面有优势时主动弃牌，让 NPC 赢取约25%资金
2. 第2轮行动窗口（1 AP）：使用「假装犹豫」→ NPC 自信心提升，误判玩家虚弱
3. 第3轮：持有强牌，突然加注到 NPC 总资金的40%
4. 第4轮行动窗口（1 AP）：使用「眼神对视」→ NPC 压力突破阈值，「损失厌恶」激活（害怕失去已赢的钱，被迫全押守住）
5. 摊牌：玩家强牌收割

**Combo 3：「温水煮蛙」—— 赌场设施 × 牌局联动**

前置条件：赌场已升级「酒吧区」和「千数后台」。AP 消耗：共 2 AP（服务生扰动1 + 轻敲筹码1）。

1. 进场前：NPC 在酒吧区消费，入场时基础压力+15（设施被动，无 AP 消耗）
2. 发牌后行动窗口（1 AP）：使用「服务生扰动」→ 全桌 NPC 压力额外+10
3. 第2轮：「记牌推算」（千数后台解锁的被动能力，自动生效）→ 精确掌握对手底牌范围，以最优解下注
4. 第3轮行动窗口（1 AP）：仅需「轻敲筹码」→ NPC 压力已在累积阈值边缘，触发「崩溃性跟注」陷阱
5. 结果：NPC 自己把资金打光，玩家以极低 AP 消耗完成收割

## 四、肉鸽 Build 体系与流派构建

### 牌局 Build 运作逻辑

```
赌场设施等级 → 决定能力池的广度和稀有度（设施是能力进池的门槛）
    ↓
每次开牌局 → 从池中随机抽 5-7 张，玩家选 3 张携带入场
    ↓
牌局过程中 → 击败 NPC 赢得的筹码可追加购买 1-2 张能力
    ↓
牌局结束 → 局内 Build 归零，能力池由设施等级永续决定
```

> **能力池成长边界**：能力池的上限由游戏内全部设施的升级层级总数决定，是有限集合，不会无界膨胀。新能力通过升级设施解锁进入池子，设施降级则对应能力暂时退出池子。

### 四大流派方向

| 流派 | 核心策略 | 依赖设施 | 无设施时 | 玩法感受 |
|------|---------|---------|---------|---------|
| **出千流** | 换牌、标记牌，直接控制牌面结果 | 千数后台（必须） | 出千类能力不进入抽池 | 外科手术式精准，低风险稳定收割 |
| **心理爆破流** | 密集小动作快速轰炸生理系统，强制触发陷阱 | 无特殊依赖，能力卡驱动 | 始终可用 | 节奏极快，高风险高爆发 |
| **情报控场流** | 偷看底牌+记牌推算，以信息碾压对手 | 情报网络、豪华包厢 | 情报类能力稀有度降低 | 下棋式掌控感，提前预判结果 |
| **环境宰客流** | 赌场设施被动联动，进场前就设好陷阱 | 重经营，多设施协同 | 联动类能力不进入抽池 | 策略部署感，NPC 踩进设计好的局 |

流派由随机抽到的能力自然形成，不是固定选择。

### 章节结构

```
章节 N
├── 普通关：2-3 场随机 NPC 牌局（经营 + 打牌交替）
├── 精英关：1 场固定精英 NPC（特定条件触发，专属弱点）
├── 章节事件：1 个剧情节点（揭露故事碎片、改变赌场状态）
└── 章节结算：赌场永久升级 + 新能力进入池子
```

关卡奖励类型受特殊条件影响，同一关卡因完成方式不同可获得经营奖励或牌局奖励，增加重玩分叉点。

### NPC 分层（类《杀戮尖塔》）

| 层级 | 类型 | 出现条件 | 价值 |
|------|------|---------|------|
| 普通 | 随机生成路人赌客 | 自动出现 | 稳定流水，练习场 |
| 精英 | 固定设计角色 | 赌场规模达标 + 特定设施组合 | 稀有能力卡、剧情碎片 |
| 特殊 | 满足章节隐藏条件触发 | 叙事事件触发 | 解锁特殊设施/剧情分支 |
| Boss | 每章节最终对决 | 章节推进自动触发 | 章节结局 + 大额解锁 |

### 破产惩罚机制

| 破产层级 | 惩罚内容 | 保留内容 |
|---------|---------|---------|
| 轻度破产 | 随机降级 1 个设施（对应能力暂出池），损失本章部分积累资金 | 主线进度、NPC 档案、能力池结构 |
| 重度破产 | 降级 2-3 个设施，当前章节需重新完成（保留章节内已解锁剧情碎片） | 主线进度、已通关章节、已解锁能力池上限 |

> **重度破产章节重玩说明**：重新完成当前章节意味着重置该章节的收益积累，但不回退故事进度。已触发的 NPC 对话和剧情碎片保留，玩家不会反复看到相同的叙事内容。

## 五、核心资源流转图

```
普通赌客流水
    +
精英牌局爆发收益
    ↓
可用资金
    ├── 投入设施扩张 → 扩充能力池上限 + 提升引流效率 + 解锁特殊 NPC 条件
    │                        ↓ 设施联动被动能力 → 牌局基础强化
    └── 购买牌局能力卡 → 本局 Build 更强 → 单场爆发收益更高
                                                    ↑
                                          （形成正向飞轮）

破产时：
    设施降级 → 能力池收窄 → 需重新投资经营恢复 → 资金压力增加
```

## 六、技术实现参考（Godot 4）

（详见 `task_00_macro_architecture.md` 及后续技术文档）

- NPC 三大系统实现为继承 `Resource` 或 `RefCounted` 的纯数据类
- 状态变更通过带参信号广播，由场景树监听表现
- 强制静态类型声明，GUT 框架覆盖核心逻辑测试
- 经营模块、牌局引擎模块、NPC 系统模块通过 EventBus 解耦通信
- 能力池作为纯数据结构（`Array[AbilityData]`）由 EconomyManager/FacilityManager 管理，与场景树解耦
