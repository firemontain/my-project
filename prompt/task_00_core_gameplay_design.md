# 核心任务：完善核心玩法与游戏循环 (Core Gameplay Loop Design)

你现在是一位拥有丰富独立游戏开发经验的主策划兼主设计师。
我们需要为你打磨一款融合了“赌场模拟经营”与“肉鸽心理战扑克”的独立游戏的核心玩法。在进入技术架构讨论之前，请帮我梳理并完善游戏的“核心循环”与“爽点”。

## 游戏核心基调与明确限制（非常重要）
1. **核心玩法载体**：玩家亲自下场的主力游戏是**梭哈（五张种马 / Show Hand，类似电影《赌神》）**。后期极少数特殊关卡可能引入其他赌局，但梭哈是绝对核心。
2. **肉鸽驱动力（关卡目标）**：游戏采用关卡制（如按“周”或“天”结算）。每一关有必须达到的“赚取金额”或“特殊目标”。金额可来源于赌场自动经营，但**玩家亲自下场设局是赚钱最快、也是流派构建（Build）的绝对主流**。达不到目标即破产（Game Over），进入局外成长结算。
3. **核心体验（心理操纵 > 牌技）**：玩家不需要苦练扑克技术。随着游戏推进，玩家会解锁越来越强的“场外能力”（如：偷看底牌、给对手施压、出千换牌、微表情诱导等）。**游戏的核心乐趣在于“把控牌局以操控 NPC 的心理”，让玩家体验到降维打击的掌控感。**

## 前置设定：NPC 的“三位一体”心理引擎
为了让你更好地理解我们的设计意图，我们在底层将赌徒 NPC 的大脑运作拆解为三个系统。玩家的所有操作，最终都是为了攻击或利用这三个系统：
- **生理系统**：计算兴奋度与压力值。随牌局起伏和玩家的施压/小动作实时波动。
- **理性系统**：计算牌面胜率（EV）。在正常状态下控制 NPC 进行理性的跟注/弃牌。
- **赌徒陷阱系统**：环境或生理指标达到阈值时触发（如“损失厌恶”、“连赢上头”），强制暴击并覆写理性系统的决策，让 NPC 做出极其非理性的重注。
