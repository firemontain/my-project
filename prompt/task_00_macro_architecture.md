# 当前任务：游戏核心概念补全与全局架构蓝图

我们目前有一个关于独立游戏的初步构想：融合了“赌场经营”与“肉鸽心理战扑克”。
在进入具体的模块开发前，我需要你作为主策划兼主架构师，帮我把目前的模糊需求进行延伸完善，并给出一套全局的系统框架。

## 游戏核心构想回顾：
1. **双层循环**：外层是类似《小丑牌》的关卡制经营（面对定期扣除的房租/目标金额，通过购买设施引流）；内层是玩家亲自下场，通过特殊能力操控具有心理弱点的 NPC 赢取暴利。
2. **Meta-progression (局外成长)**：破产后可以保留资源，解锁新的小动作、赌场初始加成等。
